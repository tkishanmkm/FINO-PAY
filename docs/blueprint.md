# **App Name**: FinoPay

## Core Features:

- Login Page: Implement a login page with PIN and Face ID options.
- Dashboard: Create a dashboard displaying balance, account actions, and trending info.
- Account Details: Enable viewing account details with mini-statements and fund transfer options.
- Passbook: Develop a transaction history (passbook) page with filtering and analysis.
- Fund Transfer: Allow users to transfer funds to saved payees and add new ones.
- Profile Page: Implement a profile page with user details, KYC options, and logout.
- AI Statement Analysis: Use Genkit tool for bank statement analysis via text input and display the summarized insights.

## Style Guidelines:

- Primary color: Violet-blue (#8A2BE2) to represent trust and innovation.
- Background color: Light gray (#F5F5F5), to complement and soften the blue for comfortable readability.
- Accent color: Light blue (#ADD8E6) for interactive elements and highlights.  
- Body and headline font: 'Inter' sans-serif for a clean, modern user interface.
- lucide-react icon set, simple and modern, matching the minimalist design.
- Mobile-first layout with a fixed header and bottom navigation, using a light gradient background for the main content area.
- Subtle transitions and animations for UI elements, enhancing user experience (e.g., page transitions, loading states).
